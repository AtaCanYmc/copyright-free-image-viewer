# Security Policy

## Supported Versions

Currently, only the latest release of `copyright-free-image-viewer` receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| > 1.0.0 | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

Security is highly important to us. If you discover a security vulnerability within this project (such as insecure handling of downloaded files, XSS in the gallery interface, or path traversal issues), please do **not** open a public GitHub issue.

Instead, please report it privately:
1. Contact the repository owner via email, or
2. Use the "Security Advisories" -> "Report a Vulnerability" feature directly on GitHub if available on the repository.

We will review all reports and try to respond as quickly as possible. When reporting a vulnerability, please include:
- A detailed description of the vulnerability.
- Step-by-step instructions to reproduce the issue.
- Any potential impact on users or systems.

Thank you for helping keep the community safe!
